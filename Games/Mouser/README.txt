NEON VANGUARD — THE LAST LIGHT IN THE VOID
An original browser-based arcade survival game by AppeXio Devs.

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. For web hosting, upload index.html, style.css, and game.js together to the same folder on your host.

CONTROLS
W / A / S / D  Move
Mouse           Aim
Left Click      Fire pulse cannon
Space           Phase dash (brief invulnerability)
P or Escape     Pause / resume
Sound button    Toggle sound effects

GAMEPLAY
Survive endless waves of hostile drones. Collect energy shards to restore hull integrity.
Every fifth wave brings an elite boss. Score increases for eliminations and cleared sectors.

CREDITS
