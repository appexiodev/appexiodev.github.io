APEX DRIFT — APPEXIO DEVS
========================
A browser-based 3D neon-city traffic racer.

HOW TO PLAY
1. Extract the ZIP file to a folder.
2. Open index.html in a modern browser (Chrome or Edge recommended).
3. Keep an internet connection active so the Three.js 3D engine and fonts can load.
4. Click START ENGINE.

CONTROLS
Arrow Left / A  - Steer left
Arrow Right / D - Steer right
Arrow Up / W    - Accelerate
Arrow Down / S  - Brake
Shift           - Nitro boost
P or Escape     - Pause / resume
Enter           - Start a new run from the garage/game-over screen
On phones/tablets, use the on-screen left, right and N2O buttons.

FEATURES
- 3D supercar, wheels, lights, neon road, skyline and street lamps
- Traffic to dodge, nitro pickups, collision feedback and score system
- Personal best saved locally in the browser
- Different garage/menu layout from the previous AppeXio game
